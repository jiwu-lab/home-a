# JIWU Mission Network · 편한IT 웹사이트

하나님의 마음을 품고 세상을 밝히는 JIWU Mission Network 대표 박기현의 사역과 AI 교육(편한IT) 안내 및 자료 공간입니다.

이 리포지터리는 Hugo와 Hugo Blox 템플릿을 기반으로 제작되었습니다.

## 📚 관련 문서 (Documentation)

이 프로젝트의 상세 제작 가이드 및 문제 보고서는 아래 링크를 확인해 주세요.

* [제작 매뉴얼 (Manual)](docs/manual.md)
* [문제 보고서 (Issues Tracker)](docs/issues.md)

## 🚀 로컬 실행 방법 (Quick Start)

웹사이트를 로컬에서 구동하려면 아래 명령어를 사용하세요:

```bash
npx hugo server -D
```
서버 구동 후 브라우저에서 `http://localhost:1313/` 에 접속하시면 확인하실 수 있습니다.
